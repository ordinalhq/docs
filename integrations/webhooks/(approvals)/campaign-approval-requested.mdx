---
title: "campaign.approval.requested"
description: "Fired when someone requests approval from users for a campaign"
sidebar:
  label: "campaign.approval.requested"
---

All webhook payloads follow a consistent top-level structure with event-specific data nested within the `data` object.

<TypeTable
  type={{
    "type": { type: "string", required: true, description: "The event type (e.g. campaign.approval.requested)." },
    "data": { type: "object", required: true, description: "Event-specific payload for this webhook." },
    "data.approval": { type: "object", required: true, description: "Approval request context for the campaign." },
    "data.approval.campaign": { type: "object", required: true, description: "Campaign being approved. Contains id, name, startDate, and endDate." },
    "data.approval.workspace": { type: "object", required: true, description: "Workspace the campaign belongs to. Contains id, slug, and name." },
    "data.approval.createdApprovals": { type: "array", required: true, description: "New approval requests created by this action. Each item has id, isBlocking, message, dueDate, createdAt, status (Requested), user (approver), and requestedBy (who asked for approval). User objects contain id, firstName, lastName, and email. Dates are ISO 8601 strings where present." },
    "data.approval.existingApprovals": { type: "array", required: true, description: "Approvals already on the campaign before this request. Each item is either a requested approval (status Requested) or an approved one (status Approved). Approved items include approvedAt and approvedBy." },
    "createdAt": { type: "string", required: true, description: "ISO 8601 timestamp when the webhook event was created." },
  }}
/>
