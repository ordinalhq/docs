---
title: "post.inline_comment.created"
description: "Fired when an inline comment (text-anchored comment) is added to a post. One event per comment, including replies in a thread."
sidebar:
  label: "post.inline_comment.created"
---

All webhook payloads follow a consistent top-level structure with event-specific data nested within the `data` object. Inline comments attach to specific text in a post—this event fires for each new comment or reply in a thread.

<TypeTable
  type={{
    "type": { type: "string", required: true, description: "The event type (e.g. post.inline_comment.created)." },
    "data": { type: "object", required: true, description: "Event-specific payload for this webhook." },
    "data.comment": { type: "object", required: true, description: "The inline comment." },
    "data.comment.thread": { type: "object", required: true, description: "The inline comment thread. Contains id, channel (channel the highlighted text is in), highlightedText (the anchored text), resolved, createdAt, and updatedAt." },
    "data.comment.id": { type: "string", required: true, description: "Comment ID." },
    "data.comment.message": { type: "string", required: true, description: "Comment message text." },
    "data.comment.post": { type: "object", required: true, description: "Post the comment was added to. Contains id, title, and url." },
    "data.comment.workspace": { type: "object", required: true, description: "Workspace the post belongs to. Contains id, slug, and name." },
    "data.comment.createdBy": { type: "object", required: true, description: "User who added the comment. Contains id, firstName, lastName, and email." },
    "data.comment.createdAt": { type: "string", required: true, description: "ISO 8601 timestamp when the comment was created." },
    "createdAt": { type: "string", required: true, description: "ISO 8601 timestamp when the webhook event was created." },
  }}
/>
