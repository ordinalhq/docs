Team engagements make it easy for your team to like, comment, and repost a scheduled post from their connected accounts after it publishes. Choose the engagement actions and team members for each post, then coordinate their timing to support the post's initial visibility.

![Team Engagements](/images/team-engagements-yc.jpg)

<Note>
  **Plan availability:** Starter workspaces can only add team engagements from the same account as the posting account. Pro workspaces can use any connected account for team engagements.
</Note>

## Engagement types

| Type            | What it does                                             | Timing                                        |
| --------------- | -------------------------------------------------------- | --------------------------------------------- |
| **Team Likes** | Make it easy for selected connected profiles to like the post | Configurable window (10 minutes to 24 hours) |
| **Team Comment** | Help a selected team member add a first comment (great for CTAs, hashtags, or links) | Configurable delay (immediate to 24 hours) |
| **Team Repost** | Help a selected team member reshare from a connected account | Configurable delay (immediate to 24 hours) |

## Platform support

Not all platforms support every engagement type due to API limitations:

| Platform  | Team Likes | Team Comment | Team Repost |
| --------- | ---------- | ------------ | ----------- |
| LinkedIn  | ✅         | ✅            | ✅           |
| Twitter/X | ✅         | ✅            | ✅           |
| Instagram | ❌         | ✅            | ❌           |
| Facebook  | ❌         | ✅            | ❌           |

For platform-specific details, see each [channel's documentation](/social-profiles/overview).

### X (Twitter) eligibility

Because of X API restrictions, only certain accounts can comment or repost on a tweet:

- The **posting account** is always eligible.
- Any other connected X account must be **@mentioned in the text of the first tweet** to be eligible.

If a connected X account isn't @mentioned, it's disabled in the Team Comment and Team Repost profile pickers. Add the account's `@handle` to the first tweet to unlock it. This rule is enforced everywhere engagements are configured, including the post editor, the [public API](/api/introduction), and [MCP tools](/mcp/tools).

<Note>
  Only text `@mentions` count. Tagging an account in an image or video does not make it eligible.
</Note>

## Setting up team engagements

1. Open a post and scroll to the **Team Engagements** section.
2. Select the engagement type(s) you want to add (Like, Comment, or Repost).
3. Select which connected account(s) should take the action.
4. For comments and reposts, write the content.
5. Set a delay for each engagement using the delay input (see [Timing](#timing)).
6. After the post publishes, team members can complete the selected engagement actions from their connected profiles.

<Check>
  Team engagements are configured per post, so set them up before the post publishes.
</Check>

## Timing

Every engagement uses a delay you set in the numeric delay input. Enter a number, then choose **mins** or **hr** for the unit. The input also suggests common presets and a **Recently used** list of delays you've recently saved in this workspace, making it easier to coordinate when team members engage.

- **Team Likes** — the value sets the window in which team members can like the post after it publishes. Minimum is **10 minutes**.
- **Team Comment and Team Repost** — the value sets how long after publishing team members can add the comment or repost. Minimum is **0** (immediate).

The maximum delay for any engagement is **24 hours**. Values outside the allowed range are rejected when you save the post.

<Note>
  Team engagements must be added **before** the post is published. Adding team engagements after a post has already been published from Ordinal will not work.
</Note>

## Best practices

- **Use responsibly** - A few strategic engagements complement genuine activity. Don't overdo it.
- **Vary your patterns** - Avoid identical timing or comments on every post.
- **Add value with comments** - Generic "Great post!" comments don't help. Add context, a question, or a useful link.
