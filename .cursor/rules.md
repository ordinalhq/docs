# Ordinal docs

This site is built with Blume, not Mintlify. Mintlify components (`<Note>`, `<ResponseField>`, `<AccordionGroup>`, FontAwesome icons) do not render here.

Follow `CLAUDE.md` at the repo root: it covers where content goes, Blume syntax, frontmatter rules, sidebar `meta.ts` files, the OpenAPI specs, and the writing style.
