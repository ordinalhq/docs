---
title: "post.published"
description: "Fired when a post is successfully published to a social channel"
sidebar:
  label: "post.published"
---

All webhook payloads follow a consistent top-level structure with event-specific data nested within the `data` object.

<TypeTable
  type={{
    "type": { type: "string", required: true, description: "The event type (e.g. post.published)." },
    "data": { type: "object", required: true, description: "Event-specific payload for this webhook." },
    "data.post": { type: "object", required: true, description: "The published post." },
    "data.post.id": { type: "string", required: true, description: "Post ID." },
    "data.post.title": { type: "string", required: true, description: "Post title." },
    "data.post.channel": { type: "string", required: true, description: "Channel where the post was published (e.g. LinkedIn, Twitter)." },
    "data.post.campaign": { type: "object | null", description: "Campaign if the post is assigned to one. Contains id, name, startDate, and endDate." },
    "data.post.url": { type: "string", required: true, description: "Ordinal post URL." },
    "data.post.postUrl": { type: "string | null", description: "Published URL on the social platform." },
    "data.post.profile": { type: "object", required: true, description: "Profile that published the post. Contains id, name, and detail." },
    "data.post.workspace": { type: "object", required: true, description: "Workspace the post belongs to. Contains id, slug, and name." },
    "data.post.publishedBy": { type: "object", required: true, description: "User who triggered the publish. Contains id, firstName, lastName, and email." },
    "data.post.publishedAt": { type: "string", required: true, description: "ISO 8601 timestamp when the post was published." },
    "createdAt": { type: "string", required: true, description: "ISO 8601 timestamp when the webhook event was created." },
  }}
/>
