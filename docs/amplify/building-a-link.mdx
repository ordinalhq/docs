An Amplify link is built from actions. Add one or more, write the copy recipients will use, then create the short link you send out.

<Steps>
  <Step title="Create a link">
    Open **Amplify** in the sidebar and create a link. Give it an internal title. This title is for your team; recipients see the public **Link Title** you set when you create the short link.
  </Step>
  <Step title="Add an Engage with a post action">
    Choose **Engage with a post** and pick the LinkedIn post recipients will engage with:

    - **Scheduled Posts** lists upcoming posts scheduled in Ordinal.
    - **Live Posts** lists every post from the last two weeks on any connected LinkedIn profile. Use the **All accounts** filter to narrow it to one profile, search for a post, or click **Refresh Posts** to pull in the latest.

    Then choose which engagements recipients can do: like (with the reaction types you allow), comment, and repost. Prewrite one or more comment variants and repost commentary variants so nobody has to think of what to say.
  </Step>
  <Step title="Add a Publish a post action">
    Choose **Publish a post** and write one or more LinkedIn copy variants. Attach images, a video or a PDF to a variant. Recipients post a variant from their own profile and can edit the copy; the media stays as you attached it.
  </Step>
  <Step title="Add a brief and labels">
    In the settings sidebar, write a **Brief** for recipients. It shows at the top of the share page. Add labels to the link the same way you label posts.

    Add another action if you want both kinds in one link.
  </Step>
  <Step title="Create the short link">
    Click **Create Amplify Link**. Set the public **Link Title** and the URL slug under **Customize URL**. Ordinal creates a short link on your connected [Dub](/integrations/dub) domain, or on ordnl.link if you have not connected one. Copy the link from the sidebar.
  </Step>
</Steps>

<Frame>
  ![Create Amplify Link modal with Link Title and Customize URL filled in](/images/amplify/create-link.png)
</Frame>

:::note
Once the link is created, the actions, the target post and the slug are locked. You can still change the titles, the brief, the variants and the engagement toggles. See [what you can edit on a live link](/amplify/analytics-and-editing#editing-a-live-link).
:::
