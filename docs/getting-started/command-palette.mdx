The command palette lets you search your content and move around Ordinal without using the sidebar. Use it to find a post, idea, or campaign by name. You can also jump straight to a page or setting, or run an action on the page you're viewing.

## Opening the command palette

Press `⌘K` on Mac or `Ctrl+K` on Windows and Linux. The shortcut works on every page in Ordinal, including settings pages.

:::note
Inside the post editor, `⌘K` / `Ctrl+K` opens the link menu instead of the command palette.
:::

## Searching

Start typing to search posts, ideas, and campaigns by title. The palette shows up to 10 matches, grouped by type. Post results include channel icons and dates.

Use the tabs under the search box to narrow your results:

| Tab           | Shows                                            |
| ------------- | ------------------------------------------------ |
| **All**       | Matching posts, ideas, and campaigns, plus pages and page actions |
| **Posts**     | Posts only                                       |
| **Ideas**     | Ideas only                                       |
| **Campaigns** | Campaigns only                                   |
| **Pages**     | Pages and settings you can jump to               |

## Jumping to a page

Type the name of a page, such as "Approvals", "Labels", or "Billing", and press `Enter` to go there. Pages are grouped as **Go to**, **Settings**, and **Agency**, plus any admin sections you have access to.

The palette lists only the pages you can open in your workspace. For example, agency pages appear only if you belong to an agency.

## Page actions

Some pages add their own commands under **This page**. For example, when you have a post open, select **Copy link** to copy the post's URL to your clipboard.

## Keyboard shortcuts

| Key                      | Action                                  |
| ------------------------ | --------------------------------------- |
| `⌘K` / `Ctrl+K`          | Open the command palette                |
| `↑` / `↓`                | Move through results                    |
| `←` / `→`                | Switch tabs                             |
| `Enter`                  | Open the highlighted result             |
| `Esc`                    | Close the command palette               |
